# ROCKET-LEAGUE-TIPS-AND-MECHANICS

Mini web en español con las mecánicas más importantes de Rocket League y tips prácticos para mejorar.

## Contenido
- `index.html`: estructura de la página.
- `styles.css`: estilos y diseño responsive.

## Cómo abrirla
Abre `index.html` directamente en tu navegador o sirve la carpeta con un servidor estático.
